# Respuesta generada — Spec del skill `nuevo-adr`

**Nombre:** nuevo-adr

**Resumen:** Skill procedural que valida y genera un ADR con formato canónico, garantizando completitud mínima y auto-incrementando el número basado en `docs/adr/`.

**Entradas:** contenido propuesto del ADR (título, contexto, decisión, alternativas, consecuencias), y acceso a `docs/adr/` para determinar el siguiente número.

**Salidas:** ADR validado con número asignado y estructura canónica listo para revisión humana; o lista de errores de validación si faltan alternativas válidas o consecuencias negativas.

**Comportamiento / Reglas clave:**
1. Validación de campos obligatorios: título, estado, contexto, decisión, alternativas (>=1 reales), consecuencias (>=1 negativa o trade-off).
2. Rechaza alternativas que sean solo "no hacer nada" u otras no sustantivas; exige trade-offs reales.
3. Rechaza ADRs sin consecuencias negativas explícitas.
4. Auto-incrementa número del ADR consultando `docs/adr/` y propone nombre de archivo `docs/adr/000X-<slug>.md`.

**Restricciones:**
- Procedural: no propone decisiones ni juzga calidad.
- No edita ADRs existentes.
- Respuesta en español.

**Formato de salida sugerido:**
- `status: ok` + `file: docs/adr/000X-...` si válido, y luego el contenido del ADR completo.
- `status: error` + lista de campos faltantes o insuficientes si rechaza.

**Criterio de éxito:** Al invocar el skill con un borrador de ADR, devuelve un ADR numerado y completo o explica por qué fue rechazado.
